# EPRS production workbench

## 1. Visual Theme & Atmosphere
An editorial field notebook: restrained controls, useful evidence, generous space. Beautiful UI informs progressive disclosure and compact status, adapted to EPRS.

## 2. Color Palette & Roles
Paper #f5f4ef; ink #242923; muted text #657060; separator #d6dbd0; interactive forest #335940; input surface #fffefa; focus #8ca988. No color-only status.

## 3. Typography Rules
System UI sans-serif for controls and evidence, 15px/1.6 body, 12–13px labels. Georgia serif for the 38–64px title, 1.08 line height. Uppercase section labels use .12em tracking.

## 4. Component Stylings
Controls have 7px corners, 11px padding and hairline borders. Primary buttons are forest with white text, 44px minimum height, darker hover #25432e. Focus is a 3px outline. Cards are flat rows separated by rules. Details expand optional controls. Import errors use the persistent live status region.

## 5. Layout Principles
1120px maximum width, 32px page inset, two equal columns with 56px gap. Spacing uses 8/16/24/32/56px. Avoid nested cards.

## 6. Depth & Elevation
No shadows or floating panels. Paper, light inputs and rules establish hierarchy.

## 7. Do's and Don'ts
Show provenance and uncertainty. Export real briefs. Never imply that local form submission runs a producer or publishes a video. Use textContent for external data. Do not expose private voice references.

## 8. Responsive Behavior
Below 760px use one column and 22px insets. Keep buttons at least 44px high. Respect reduced motion; no decorative continuous animation.

## 9. Agent Prompt Guide
Use paper #f5f4ef, ink #242923 and forest #335940. Build compact labelled controls, plain status and expandable detail. Keep wildlife context distinct from media reuse and audio identity. Reference: https://www.beautifului.dev/ (checked 2026-09-05).
