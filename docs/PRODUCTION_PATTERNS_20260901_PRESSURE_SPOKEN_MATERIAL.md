# Pressure Leaves a Trace: short speech as material

Date: 2026-09-01

This production tested a reference-free synthetic speech lane as a musical
material rather than as a simulated human singer. The final study uses six
short English cues from Qwen3-TTS CustomVoice, a fixed D pedal, a 24-bar 6/4
grouped-3+3 BeatScript, and a square deterministic material film. The public
package discloses synthetic media because synthetic speech is present in the
final audio.

## Method comparison

The recent catalog included an instrumental 5/4 grouped-3+2 portrait-card
exchange and a 2/4 wildlife-knock woodcut. This run changes the meter, tempo,
source/performance mode, form, visual subject, palette, typography, thumbnail
silhouette, and aspect ratio. It deliberately avoids readable UI language,
signal/relay metaphors, faces, logos, stock media, system TTS, and voice-clone
claims.

The useful result was not “the model makes a song.” It was narrower: short
speech cues are cheap to re-render, so the creative bottleneck moves to
phrasing, silence, density, and the listener's ability to hear a physical
consequence. A 20.4-second cue crowded the sparse afterpressure gap; a separate
3.76-second replacement left the gap audible and became the final cue. Both
attempts remain in the song-local evidence.

## Tool notes

- [Qwen3-TTS technical report](https://arxiv.org/abs/2601.15621) and the
  [official Qwen3-TTS repository](https://github.com/QwenLM/Qwen3-TTS) were
  used as primary documentation for the bounded local test.
- [Sonic Pi's official tutorial](https://sonic-pi.net/tutorial.html) and the
  [Sonic Pi v5.0.0 release](https://github.com/sonic-pi-net/sonic-pi/releases/tag/v5.0.0)
  were checked for current synthesis and timing ideas. Sonic Pi was not forced
  into this release because the speech-led BeatScript method fit the concept
  more directly.
- Pillow authored the square frames; FFmpeg/ffprobe performed deterministic
  assembly and media checks; EPRS supplied the evidence, approval, release,
  and publication contracts.
