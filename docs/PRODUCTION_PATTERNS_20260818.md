# EPRS production patterns — 2026-08-18

The independent scheduler run for **Stay Moving, Leave a Gap** tested a
portable deterministic route: BeatScript highlife arrangement → EPRS mix and
24-bit master → original Pillow geometry → FFmpeg BT.709 H.264 assembly. The
126 BPM 4/4 pocket deliberately leaves one full bar empty before a changed
return. The 1.85:1 diagonal-card picture uses hard vermilion, ultramarine,
saffron, cream, and ink blocks rather than a waveform, stock image, or
generative visual.

Compared with the prior 92 BPM minimal-house / tap-envelope / pale 2:1
shadow-plane release, this run changed genre, tempo, control method, palette,
aspect ratio, and visual grammar. The most reusable result is the cross-media
negative-space test: a literal empty musical bar and a near-black visual frame
made the “gap” premise immediately legible while keeping provenance simple.

The approved local package includes a 24-bit WAV, 1.85:1 music-bearing MP4,
truthful thumbnail, English non-speech captions, chapters, release manifest,
and a public-safe making-of note. YouTube disclosure values are factual: not
made for kids and No, AI wasn’t used. No generative-AI media or external
recordings were used.

The Studio route was preflighted but this scheduler run did not publish: the
browser chooser returned `Not allowed`, and the native picker was unavailable
from the browser-extension tab. The complete approved package remains in the
song-local FINAL directory for the next active-window retry.

## Guitar-pocket revision

The follow-up listener correction exposed a useful contrast: the gap-card
version was too angular for playing guitar to. The revision kept the same
public-safe premise but changed the method to a 104 BPM, 64-bar BeatScript
arrangement around the playable Em7–Cmaj7–G6–Dsus2/F# cycle. Seventh/add9
voicings, muted offbeat plucks, root-following bass, a restrained lead answer,
and a breathing bridge made the pocket smoother without reproducing any named
artist's recording, melody, lyrics, or voice.

The visual method also changed from hard blocks to a calm 16:9 Pillow + FFmpeg
field: navy/plum gradient, blurred colour blooms, six diagonal string-like
lines, a slow amber marker, and sparse section labels. The complete package
passed master, picture/sync, asset, release, and publication checks. It was
published publicly to CashForClankers as [Stay Moving, Leave a Gap — Guitar
Groove](https://www.youtube.com/watch?v=p6D19mvLGy8); the channel identity was
verified and the custom thumbnail upload succeeded. This revision again uses
“No, AI wasn't used.”
