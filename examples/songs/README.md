# Publishable song examples

This directory is for deliberately curated teaching projects—not active personal workspaces.

Before adding an example:

- include editable text/code sources instead of large renders;
- confirm rights for every recording, sample, image, font, and performance;
- remove personal paths, private notes, and unnecessary timestamps;
- use fictional or contributor-approved names and credits;
- keep generated audio/video in ignored build directories when practical;
- run `make public-check`, `make check`, and `make test`.

Active creative projects belong in the Git-ignored `songs/` directory.
# Public song tests

The repository keeps personal sessions out of Git. The BeatScripts in
`examples/beats/` are self-contained public test songs for three different
production instincts:

- `sub-pressure-club.beat` tests four-on-the-floor low-end pressure and lift.
- `family-room-space.beat` tests sparse call-and-response room for performers.
- `glass-half-time.beat` tests fast surface motion over a half-time backbeat.

Render any one with `scripts/eprs render`, inspect it with `scripts/eprs
analyze`, and create a rhythm map with `scripts/eprs visualize`. They are test
material, not claims of a mastered or human-approved release.
